Nó hoạt động dựa trên GitHub Actions. Token được cấu hình trong Settings → Secrets and variables → Actions của repo bạn.
Bắt buộc — không cần làm gì, tự động có sẵn:
- GITHUB_TOKEN — GitHub tự sinh ra.
Tùy chọn (nếu thiếu, pipeline sẽ bỏ qua sạch sẽ):
- PRODUCTHUNT_TOKEN
- REDDIT_CLIENT_ID + REDDIT_CLIENT_SECRET
- YOUTUBE_API_KEY
- LLM7_TOKEN
- TELEGRAM_BOT_TOKEN + TELEGRAM_CHANNEL
